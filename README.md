# drawingService / «Крокодил»

Один Go-репозиторий, две команды:

- `cmd/drawing-service` — прежнее API рисунков и штампов с Google Drive; старые методы сохранены.
- `cmd/crocodile` — самостоятельный API игры, без Google Drive.

Игра: [draw.wedding-en.ru](https://draw.wedding-en.ru/).

Документация находится в **[docs](docs/README.md)**: правила игры, локальный запуск, API, хранение данных и деплой.
